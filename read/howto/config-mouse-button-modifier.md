# 設定「Mouse Button Modifier」


## 說明

| 滑鼠按鍵組合                |  功能                   |
| --------------------------- | ----------------------- |
| `Win + [滑鼠左鍵按住拖曳]`  | 視窗移動                |
| `Win + [滑鼠右鍵按住拖曳]`  | 視窗更改大小            |


> 目前在「Cosmic Desktop」預設的「Mouse Button Modifier」就是「`Win`」，所以目前還沒有去探究如何修改。




另外因為我慣用「Win鍵」的「按鍵組合」來操作一些「視窗動作」，

例如「`Win + q` => 視窗關閉」，「`Win + m` => 視窗最大化」。

預設按下「Win鍵」會觸發「顯示主要功能選單」，

為了避免無謂的干擾，我會[停用這個功能](https://samwhelp.github.io/note-about-popos-cosmic/read/howto/disable-keybind-open-main-menu.html)。
